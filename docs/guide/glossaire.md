---
title: "Glossaire"
description: "Retrouvez les termes utilisés dans Artiforce : avoir, reste dû, situation de travaux, archivage, clé API, webhook, calendrier ICS et idempotence."
---

| Terme | Signification |
| --- | --- |
| Espace d’entreprise | Ensemble des données, membres et réglages d’une entreprise. Dans l’API : `tenant`. |
| Propriétaire | Membre qui dispose des fonctions de gestion réservées à l’entreprise. |
| Brouillon | Document en préparation, avant finalisation. |
| Avoir | Document qui corrige tout ou partie d’une facture. |
| Reste dû | Montant restant à régler après affectation des paiements et corrections. |
| Situation | Facturation d’une partie de l’avancement d’un chantier. |
| Archivage | Rangement hors du suivi courant, distinct de la suppression et de la conservation légale. |
| Clé API | Secret donnant à un logiciel des droits limités pour agir au nom d’un membre. |
| Webhook | Notification envoyée à un logiciel lorsqu’un événement se produit. |
| ICS | Format de calendrier utilisé pour publier ou consulter des événements. |
| Fenêtre d’arrivée | Intervalle annoncé au client pour le début de l’intervention. |
| Idempotence | Possibilité de rejouer une même demande sans créer plusieurs fois la même opération. |
| Plateforme agréée | Prestataire qui opère les échanges de facturation électronique concernés. |
