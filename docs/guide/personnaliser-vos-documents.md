---
title: "Personnaliser vos documents"
---

Ouvrez les réglages d’apparence des documents pour choisir le modèle de vos devis et factures.

## Préparer votre présentation

- Ajoutez votre logo et, si nécessaire, un second logo.
- Choisissez les couleurs et le modèle de document.
- Vérifiez les coordonnées, l’identité légale, les mentions de paiement et les coordonnées bancaires.
- Contrôlez le résultat dans l’aperçu PDF, notamment sur plusieurs pages.

Les modèles disponibles comprennent Classique, Bandeau, Colonne, Épuré et Tableur. Choisissez une présentation lisible pour vos clients, en particulier si les devis comportent beaucoup de lignes ou de sections.

## Conserver la trace de ce qui a été émis

Une modification des réglages ne réécrit pas les factures déjà finalisées. Les informations de présentation et d’identité conservées sur un document émis permettent de retrouver la version utilisée à ce moment-là.

Pour un document historique importé, gardez le fichier d’origine comme référence. Un aperçu reconstitué ne doit pas être confondu avec l’original.
