## Lire chaque état séparément

| Information | Ce qu’elle indique |
| --- | --- |
| Brouillon | Le document peut encore être préparé et corrigé. |
| Finalisé | Son contenu et son numéro ont été fixés. |
| Envoyé | Un envoi a été effectué ; consultez son suivi pour connaître son résultat. |
| Partiellement payé | Un règlement a été affecté, mais un reste dû subsiste. |
| Payé | Le montant attendu est couvert par les règlements et régularisations enregistrés. |
| Archivé | Le document est retiré du suivi courant et reste consultable dans les archives. |

Le statut commercial d’un devis, l’envoi d’un e-mail, le paiement d’une facture et sa transmission électronique décrivent des événements différents. Une acceptation de devis ne prouve pas un paiement.

## Corriger une facture

Une facture finalisée ne se modifie pas comme un brouillon. Utilisez un avoir pour la correction qui le nécessite, puis vérifiez son affectation et le solde. Si un remboursement doit être effectué, distinguez le document comptable de l’opération de remboursement.

## Relancer avec le bon contexte

Avant de relancer, vérifiez le destinataire, les paiements déjà reçus et le reste dû. L’aperçu permet de relire le message prévu avant l’envoi. Une sélection de documents permet de traiter plusieurs relances ensemble ; chaque document garde son propre suivi.

Les relances automatiques et le canal SMS dépendent de leur configuration dans votre espace. Consultez les réglages avant de compter sur un envoi automatique.

## Archiver sans supprimer

Archivez les devis et factures que vous ne souhaitez plus suivre dans les listes courantes. Le filtre des archives permet de les retrouver. L’archivage d’un devis est réversible. Cette action ne remplace pas les règles de conservation de vos pièces.
