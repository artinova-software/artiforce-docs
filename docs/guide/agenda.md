L’agenda permet d’organiser les rendez-vous de votre équipe, les indisponibilités et les événements personnels. Les accès dépendent des droits du membre : un intervenant peut ne voir que les événements auxquels il est affecté.

## Configurer votre planning

Renseignez le point de départ de l’entreprise, les horaires, les membres qui peuvent intervenir, leurs compétences et les types d’intervention. Les secteurs et les durées influencent les créneaux proposés.

Un rendez-vous peut mobiliser plusieurs personnes. La durée prévue pour l’intervention et la fenêtre d’arrivée annoncée au client sont deux informations différentes. Le planning utilise l’heure de Paris ; une application connectée doit respecter ce fuseau et les changements d’heure.

## Proposer la réservation en ligne

Activez la réservation après avoir configuré une zone d’intervention, un type réservable et une personne disponible. Partagez votre lien ou intégrez le formulaire sur votre site. Selon le type d’intervention, une demande peut être confirmée directement ou attendre votre validation.

Un créneau affiché peut être pris avant la confirmation : c’est la réponse finale qui confirme la réservation.

## Retrouver les rendez-vous dans vos calendriers

Les flux ICS permettent de consulter les événements depuis un calendrier compatible. Leur actualisation dépend du service qui lit le flux : elle n’est pas nécessairement instantanée. L’adresse du flux donne accès à son contenu ; gardez-la privée.

La connexion Google Calendar nécessite une autorisation du membre concerné. Sa disponibilité dépend de la configuration du service pour votre entreprise. Consultez les guides [calendriers](/api/calendriers), [Google Calendar](/api/google-calendar) et [réservation intégrable](/api/reservation).

## Connecter un autre outil

L’[API de planification](/api/planification) permet de lire et gérer les rendez-vous avec une clé autorisée. Les [webhooks](/api/webhooks) signalent les changements aux logiciels connectés.
